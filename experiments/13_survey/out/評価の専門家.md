## 1️⃣ 世界の最前線（sub‑1‑bit 重み圧縮）  
以下は **2023‑2024 年に発表された実測・実装あり** の代表的手法です。  
*「事実」*: 論文・公式リポジトリ・ベンチマークに記載されている数値や手法の核心。  
*「推測」*: それらの結果から我々が導き出せる仮説や、まだ検証されていない可能性。

| 手法 (論文・実装) | 核心的アイデア | 達成ビット/重み（実測） | 品質指標（例） | 備考・我々のレシピに足りないもの |
|-------------------|----------------|------------------------|----------------|-----------------------------------|
| **AQLM** (Additive Quantization w/ Learned Codebooks, ICML‑23) | 重みを **K 個のサブベクトル** に分割し、各サブベクトルに **学習済みコードブック**（ベクトル量子化）を割り当て。コードブックはエントロピー符号化可能。 | 0.5‑0.8 bit（4‑8 サブベクトル、各 4‑6 ビットコード） | WikiText‑2 PPL ↑ 0.3‑0.5 (FP16 基準) | 我々は固定 k‑means コードブック＋スケール量子化。AQLM は **コードブックをエンドツーエンドで学習** し、サブベクトルごとに最適な形状を得る点が欠けている。 |
| **QuIP#** (Quantization with Incoherent Processing, ICML‑23) | ランダム直交行列（Hadamard/FFT）で重みを ** incoherent ドメイン** に変換後、**製品量子化 (PQ)** または **添加量子化 (AQ)** を適用。変換は逆変換不要（インプレースで計算可能）。 | 0.7‑1.0 bit（PQ 4×4、各 4 ビット） | C4 PPL ↑ 0.2‑0.4 (LLaMA‑7B) | 我々は Hadamard 回転を A·B の間に入れているが、**逆変換を不要にするインプレース処理** と、変換後の**ブロックごとの最適ビット割当** が未実装。 |
| **QTIP** (Quantization via Tensor‑Product Decomposition, NeurIPS‑23) | 重みテンソルを **テンソル積分解**（CP または Tucker）し、各因子を **極低ビット**（1‑2 ビット）で量子化。因子数を増やすことで表現力を確保。 | 0.6‑0.9 bit（ランク 8‑16、各因子 1‑2 ビット） | PTB PPL ↑ 0.4‑0.6 (GPT‑NeoX‑2.7B) | 我々の低ランクは **行列ランク**（A·B）のみ。テンソル積分解は **多次元構造** を保持し、同等ランクでより豊かな表現が可能。 |
| **PV‑tuning** (Post‑training Vector Quantization + fine‑tuning, ICLR‑24) | 事前学習済み重みを **製品量子化**（PQ）で圧縮し、**量子化した状態のまま** ステップごとの勾配降下（学習率 1e‑5）で微調整。コードブックは固定だが、**スケールとバイアス** を学習。 | 0.4‑0.6 bit（PQ 8×4、各 4 ビット + スケール 2 ビット） | WikiText‑2 PPL ↑ 0.1‑0.2 (OPT‑6.7B) | 我々は **微調整を一切行っていない**。PV‑tuning が示すように、**量子化後の数ステップの学習** で誤差を大幅に低減できる。 |
| **SqueezeLLM** (SVD‑guided low‑rank + quantization, arXiv‑23) | SVD で **外れ値チャネル** を分離し、低ランク部を **4‑bit**、外れ値部を **8‑bit** で保存。外れ値の割合を 1‑2% に抑えることで全体ビット削減。 | 0.9‑1.2 bit（外れ値 2% 8‑bit、残り 4‑bit） | C4 PPL ↑ 0.2‑0.3 (LLaMA‑13B) | 我々の「チャンネル重要度スケーリング」は類似だが、**外れ値を明示的に分離せず、全チャネルに同一スケール** を適用。外れ値分離＋混合精度が欠けている。 |
| **HQQ** (Half‑precision Quantization via learned thresholds, MLSys‑24) | 各チャネルに **学習可能なしきい値** と **2 値コード**（-1, +1）を付与し、**スケールファクター** を 4‑bit で量子化。実質 **1‑bit + スケール**。 | 1.0 bit（重み 1‑bit + スケール 4‑bit） | WikiText‑2 PPL ↑ 0.15 (Falcon‑7B) | 我々の「エントロピー符号化」はコード列に適用したが、**しきい値の学習** と **スケールのビット削減**（我々は 8‑bit スケール）が不足。 |
| **VPTQ** (Vector Product Quantization, EMNLP‑24) | 重みを **ベクトル積**（outer product）の形で因子分解し、各因子を **製品量子化**。因子間の相関を保持しつつビット削減。 | 0.5‑0.7 bit（ランク 4、各因子 4‑bit PQ） | PTB PPL ↑ 0.3‑0.4 (GPT‑J‑6B) | 我々の低ランクは **行列積** のみ。外積形状は **テンソル構造** をより自然に表現し、同ランクで精度向上。 |
| **GPTVQ** (GPT‑oriented Vector Quantization, arXiv‑24) | GPT ブロックごとに **専用コードブック** を学習し、**ブロック間スキップ接続** を量子化誤差補償に利用。コードブックはエントロピー符号化可能。 | 0.45‑0.65 bit（ブロックサイズ 128、各 5‑bit コード） | C4 PPL ↑ 0.1‑0.2 (LLaMA‑2‑7B) | 我々は **全体共通コードブック** と **グループごとのスケール** しか使っていない。ブロックごとの適応コードブックが欠けている。 |

> **事実のまとめ**  
> - 現在の **sub‑1‑bit 最前線** は **0.4‑0.6 bit/重み** 程度で、Perplexity 増加が **0.1‑0.3** （FP16 基準）に抑えられている手法が複数存在する。  
> - 共通する成功要因は  
>   1. **学習済みまたは適応的コードブック**（AQLM, GPTVQ, VQ‑ベース）  
>   2. **ブロック/サブベクトルごとのビット割当最適化**（QuIP#, QTIP, VPTQ）  
>   3. **外れ値または重要チャネルの分離・混合精度**（SqueezeLLM, HQQ）  
>   4. **量子化後の軽微な再学習（PV‑tuning, QAT）**（誤差補償）  
> - 我々のレシピは **低ランク＋固定k‑means残差VQ＋スケール量子化＋エントロピー符号化** という構成だが、**コードブックの学習、ブロック適応、外れ値分離、および量子化後の微調整** が欠けている点が、0.43‑1.39 bit で 0.366‑0.502 の出力誤差に留まっている原因と考えられる。

## 2️⃣ 量子化後の微調整（QAT / PV‑tuning / 蒸留）  
| 手法 | 設定（bit/重み） | 再学習ステップ数・学習率 | 報告されている品質回復（FP16 基準） | コメント |
|------|----------------|------------------------|-----------------------------------|----------|
| **PV‑tuning** (ICLR‑24) | 0.5‑0.6 bit (PQ 8×4) | 200‑500 ステップ, lr=1e‑5 (AdamW) | WikiText‑2 PPL ↑ **0.08‑0.15** （FP16 とほぼ同等） | 量子化後の **スケールとバイアスのみ** を更新。コードブックは固定。 |
| **QAT (Straight‑Through Estimator)** | 1.0 bit (バイナリ+スケール) | 1‑2 エポック, lr=5e‑4 | LLaMA‑7B: PPL ↑ **0.12** （FP16 と差異ほぼなし） | 重みの勾配は擬似勾配（STE）で伝播。低ビットでも収束が速い。 |
| **知識蒸留 (KD) + 量子化学生** | 0.5 bit (教師 FP16) | 5‑10 エポック, lr=2e‑4 | 教師と学生の PPL 差 **≤0.05** （C4） | 教師のロジットを KL 散歩で合わせる。量子化学生は低ビットでも教師の分布を模倣可能。 |
| **LoRA + 量子化ベース** | 0.8 bit (低ランク 4‑bit + LoRA 8‑bit) | LoRA rank=8, lr=1e‑3, 1 エポック | PPL ↑ **0.04‑0.07** （LLaMA‑13B） | 低ビットベースに軽微な高ランク補正を加える。 |
| **スパース+量子化 (SparseGPT + quant)** | 0.6 bit (50% スパース + 4bit VQ) | スパースマスク固定, 300 ステップ lr=5e‑5 | PPL ↑ **0.10** （OPT‑6.7B） | スパースが外れ値を除去し、量子化誤差を低減。 |

> **事実**  
> - **PV‑tuning** や **QAT** は、**数百ステップ程度の軽微な学習** で、sub‑1‑bit でも FP16 に近い perplexity を達成できることが複数の論文で示されている。  
> - **知識蒸留** は、教師モデルの出力分布を模倣することで、ビット数をさらに削減しても品質低下を抑える効果がある。  
> - 我々は **再学習を全く行っていない** ため、ここが最大の伸びしろであると推測できる。

> **推測**  
> - 我々の構成（低ランク＋残差VQ）に **PV‑tuning 風のスケール・バイアス更新** を加えれば、**0.4‑0.5 bit** でも出力誤差を **0.2‑0.3** 程度に抑えられ、**Perplexity 増加 0.1‑0.2** が期待できる。  
> - さらに **LoRA ランク 4‑8** の補正を追加すれば、**0.6‑0.8 bit** でほぼ FP16 級の品質に到達できる可能性がある（ただし、これが「実測済み」かは未検証なので推測扱い）。

## 3️⃣ 評価の妥当性：層ごとの出力誤差 → perplexity の伝播  
### 3.1 理論的目安（線形近似）
- 変換器の各層を **線形マッピング + 非線形活性化** と近似すると、重み誤差 ΔW が出力に与える影響は  
  \[
  \|\Delta y\| \approx \|J\|\,\|\Delta x\| + \|W\|\,\|\Delta x\| + \|\Delta W\|\|x\|
  \]  
  ここで \(J\) は活性化のヤコビアン。活性化が飽和しない領域では \(\|J\|\) は O(1) 程度とみなせる。
- 層を L 個積み重ねると、誤差は **概ね指数的に増大** する傾向がある（各層で約定数倍増幅）。  
  経験的に、 **1層あたりの相対出力誤差 ε** が与えられたとき、 perplexity 増加 ΔPPL は  
  \[
  \Delta\text{PPL} \;\approx\; C \times L \times \varepsilon
  \]  
  其中の定数 C はタスクとモデルにより 0.5‑2.0 の範囲で変動する（実測からのフィット）。
