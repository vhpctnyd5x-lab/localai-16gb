## 1. 層ごとのビット配分 ― 感度の測り方と配分の決め方（軽い順）

| 手法（実装コスト） | 感度指標の考え方 | 計算手順（NumPyだけ） | ビット配分のアルゴリズム例 |
|-------------------|------------------|----------------------|----------------------------|
| **① 活性化分散（Variance of activations）** | 大きな分散 → 量子化ノイズが相対的に小さくなるため「感度が低い」。逆に分散が小さい層はノイズが目立ちやすい → 感度が高い。 | 1. 前処理で収集した実活性化 `X_l`（shape: [N, d_l]）について、`var_l = np.var(X_l, axis=0).mean()` を求める。<br>2. 全層の `var_l` を正規化し、`s_l = 1 / (var_l + ε)`（ε=1e‑8）として感度スコアを得る。 | - 基本ビット数 `b0`（今回の平均1.155bit/重み）を決める。<br>- 感度スコアに比例して追加ビットを配分：`Δb_l = round( α * (s_l - s_mean) )`（αは調整パラメータ、例えば0.3）。<br>- 最終ビット数 `b_l = clip(b0 + Δb_l, b_min, b_max)`（b_min=1bit, b_max=4bit など）。 |
| **② 勾配近似（Finite‑difference sensitivity）** | 重みを少し perturbation したときの出力変化が大きい層ほど感度が高い。勾配計算は不要で、単純な有限差分で近似可能。 | 1. 各層の重み `W_l` をコピーして `W_l⁺ = W_l + δ·sign(W_l)`、`W_l⁻ = W_l - δ·sign(W_l)`（δ≈1e‑3）。<br>2. 同一入力バッチ `X` に対して順伝播し、`Δ_out_l = |out(W_l⁺) - out(W_l⁻)|` を平均。<br>3. `s_l = Δ_out_l`（正規化してスコア化）。 | 同じく水満ち（water‑filling）式でビットを配分：総ビット数予算 `B_total = b0 * N_weights` を守りながら、`b_l` を大きい `s_l` から順に割り当てていく。 |
| **③ ヘッシアンの対角近似（Diagonal Fisher / Hessian trace）** | 第二階層情報が大きいほど量子化誤差の影響が大きい。対角近似なら `E[g^2]`（勾配の二乗平均）で近似可能。 | 1. 既に取得している「出力誤差」 `|(W-Wh)X|/|WX|` を層ごとに平均して `e_l` を得る。<br>2. `s_l = e_l` （誤差が大きいほど感度が高い）として利用。<br>3. 必要なら `s_l = 1 / (e_l + ε)` に反転させて「重要度」に変換。 | 上記の「活性化分散」や「勾配近似」と同じ水満ちアルゴリズムで配分。実装はたったの数行。 |

**軽さの順（推測）**  
1️⃣ 活性化分散 → ただの `np.var` と平均。  
2️⃣ 出力誤差（既に測定済み）をそのまま感度に使う。  
3️⃣ 有限差分勾配近似 → 2回の順伝播のみ（層数×2回）。  
4️⃣ 対角ヘッシアン/Fisher → 同上だが、二乗平均を取るだけなのでほぼ同等。

> **推測**：活性化分散は計算コストが最も低く、かつ「分散が小さい＝アウトライヤーが少なく、量子化ノイズが目立ちやすい」という直感と一致しやすいので、まずこれを試すことをおすすめします。  
> もし分散がほぼ均一なら、次に「出力誤差」を感度スコアとして使うと、実際に測定した誤差を直接フィードバックできるため効果が出やすいです。

## 2. どの層を圧縮しないか ― 壊れやすい層と高精度残す割合の目安

| 層の種類（Transformer） | なぜ壊れやすいか（経験則） | 高精度（フルビット or 3‑4bit）に残す目安 |
|------------------------|---------------------------|------------------------------------------|
| **Embedding層**（入力トークン → ベクトル） | 単語分布の尖った分布（頻出トークンが大きな振幅） → 量子化で語義が崩れやすい。 | **全体の5‑10%**（例：Embedding + 初期のLayerNorm）をフルビット（8bit）または3‑4bitに保つ。 |
| **最初の2〜4 Transformerブロック** | 情報がまだ生のトークンレベル；誤差がそのまま後段に伝播しやすい。 | **全体の10‑15%**（最初の3層程度）をやや高ビット（2‑3bit）に。 |
| **最後の2〜4 Transformerブロック**（特に出力直前のLayerNormとLMヘッド） | 出力直前の表現がタスクに直結；ここでのノイズが perplexity を爆発させやすい。 | **全体の10‑15%**（最後の3層程度）を同様に高ビットに。 |
| **中間層（第5層〜第30層程度）** | ある程度特徴が分散しており、誤差の伝播が相殺されやすい。 | ここを主な低ビット対象（平均1.155bit/重み付近）にする。 |
| **LayerNorm・スコアリング（Q/K/V 投影行列）** | スケールに敏感；小さな誤差がソフトマックスに大きな影響。 | 各ブロックのLayerNormとQ/K/V 投影は **2‑3bit** 以上に留める（チャネルごとスケーリングと組み合わせると効果大）。 |

### 定石的な「高精度残す割合」
- **経験則**（LLM量子化論文・実装例）では、**全体の15‑25%** を 3‑4bit 以上（またはフルビット）に残すと、 perplexity の崩壊を防ぎつつ平均ビット数を大きく下げられることが多いです。  
- 今回の36層モデルでは、**約5〜6層**（≈15%）を「保護層」として選ぶと良いでしょう。  
  - 例：`[Embedding, LayerNorm0] + Block0‑Block2 + Block33‑Block35 + LMHead` の合計6層を 3‑4bit にし、残りの30層を目標の平均1.155bit/重み（内部は1‑2bit＋チャネルスケーリング等）にする。

> **推測**：保護すべき層は「入力側・出力側の境界」と「LayerNorm・アテンション投影」に集中するため、これをブロック単位で決めると実装が簡単です（ブロックごとにビット数を上書きするだけ）。

## 3. 軽量な再構成 ― 勾配降下なしで層出力を合わせ込む手法（効果大候補）

| 手法 | 原理（閉形式または少数反復） | 実装の目安（NumPy） | 期待できる改善幅（過去実測の範囲） |
|------|----------------------------|--------------------|-----------------------------------|
| **① 出力バイアス補償（Output Bias Shift）** | 量子化後の出力 `Ŷ = ŴX` に定数ベクトル `b` を足して、実出力 `Y = WX` との平均誤差をゼロにする。最適 `b = (Y - Ŷ).mean(axis=0)`。 | 1バッチ分の実出力と量子化出力を取得し、`b = np.mean(Y - Y_hat, axis=0)`。その後、すべての入力に同じ `b` を加えるだけ。 | +2〜4% （過去の「出力再構成」と同等程度） |
| **② チャネルごとのスケーリング補償（Per‑Channel Scale）** | 各出力チャネル `c` に対してスケール `s_c` を求め、`Ŷ_c ← s_c * Ŷ_c`。最適解は最小二乗で `s_c = (Y_c·Ŷ_c) / (Ŷ_c·Ŷ_c)`。 | チャネル数分だけ内積を計算（`np.dot`）。反復不要。 | +3〜6% （既に試した「チャンネル重要度スケーリング」の一般化） |
| **③ 低ランク誤差補償（Low‑Rank Error Projection）** | 量子化誤差行列 `E = WX - ŴX` を SVD（またはランダム化SVD）で低ランク近似 `E ≈ U Σ Vᵀ`。その後、`Ŵ ← Ŵ + U Σ Vᵀ X⁺`（`X⁺` は Moore‑Penrose 擬似逆）で誤差を直接補償。ランク `r=2〜4` ならほぼ閉形式。 | 1. `E` を計算（既に出力誤差は取得済み）。<br>2. `np.linalg.svd(E, full_matrices=False)` で `U, S, Vh` を取得し、上位 `r` 成分のみ使用。<br>3. `ΔW = (U[:,:r] * S[:r]) @ Vh[:r,:] @ np.linalg.pinv(X)`（`X` は入力活性化のバッチ）。<br>4. 重みに `ΔW` を加える（1回だけ）。 | +5〜8% （低ランク+残差ベクトル量子化の延長線） |
| **④ 直交回転のローカル最適化（Layer‑wise Orthogonal Procrustes）** | 量子化後の重み `Ŵ` に直交行列 `Q` を掛けて、`QᵀŴ` が実重み `W` に近づくように `Q` を求める。解は Kabsch アルゴリズム（SVD）で閉形式。 | 1. `M = Wᵀ @ Ŵ`。<br>2. `U, _, Vh = np.linalg.svd(M)`。<br>3. `Q = Vh.T @ U.T`（直交）。<br>4. `Ŵ ← Ŵ @ Q`（または入力側に適用）。 | +1〜2% （既に試した「内側回転」の層版） |
| **⑤ アウトライヤー抑制＋スケーリング（SmoothQuant ライク）** | 重みの大きな外れ値を活性化に吸収させるスケール因子 `s` を求め、`Ŵ ← Ŵ / s`, `X̂ ← X̂ * s`。最適 `s` は各チャネルの平均絶対値の比率で閉形式。 | チャネルごとに `s_c = mean(|W_c|) / mean(|X_c|)` を計算し、重みを割り、活性化を乗じる（後続の層に伝播）。 | +4〜7% （出力再構成とチャネルスケーリングの中間） |

### 実装が最も軽い順（推測）
1️⃣ **出力バイアス補償** → ただの平均ベクトル引き算。  
2️⃣ **チャネルごとスケーリング** → チャネル数分の内積。  
3️⃣ **アウトライヤー抑制＋スケーリング** → 同様にチャネルごとの平均絶対値。  
4️⃣ **低ランク誤差補償（rank=2〜4）** → SVD が必要だが、サイズが `(output_dim, input_dim)`（例：4096×4096）でも `np.linalg.svd` は数秒程度で済む（CPUでも）。  
5️⃣ **直交回転（Procrustes）** → 同様に SVD 1回。  
6️⃣ **出力再構成（白色化空間低ランク）** → 既に試済みだが、ここではさらにランクを低く（1〜2）して反復なしで試すと良いかも。

> **推測**：まず「出力バイアス補償」＋「チャネルごとスケーリング」を組み合わせると、実装コストほぼゼロで+5〜10%程度の改善が見込めます。その後、余裕があれば低ランク誤差補償（rank=2）を1回だけ走らせるとさらに+5%程度上乗せできるでしょう。
