# 検討依頼: この状態から、あと何ができるか

## 現状（すべて実測）
対象 qwen2.5-coder-3B。指標は出力誤差 |(W-Wh)X|/|WX|（Xは実モデルから採取した本物の活性化）。
較正と別区間のデータで採点している。

### モデル全体を圧縮して一度失敗した
平均1.155bit/重み → perplexity 5.58 が 24257 に崩壊（出力は "n n n n..."）。
1層あたりの誤差0.4〜0.5が36層積み重なると致命的。実用ラインの目安は誤差0.05〜0.1。

### 実測で有効と確認した手札
- 誤差補償(GPTQ): +5.6〜39.9%（本物の活性化で初めて効いた。最大の武器）
- チャンネル重要度スケーリング: +5〜24%（α=0.75が最適）
- 出力再構成(白色化空間での低ランク): +4.7〜6.6%
- 低ランク+残差ベクトル量子化: 主力の骨格
- 内側回転(A・Bの間の直交行列、積は不変): +2%
- エントロピー符号化: 3〜5%
- トレリス符号化: 1bitで誤差0.5114（シャノン限界0.500まで2%、コードブック不要）
統合レシピで1層あたり+14〜27%改善を確認。いまモデル全体に適用中。

### 効かなかったもの
全体回転(ベクトル量子化には有害) / 文脈モデル(ゼロ) / 交互精錬(ノイズ内) /
層をまたぐ基底共有(論文で否定済み)

### 制約
Intel Mac / 16GB RAM / CPUのみ / numpy実装。勾配降下による再学習は資源的に困難。
252層の量子化に約4時間かかる。

## 聞きたいこと
1. 層ごとのビット配分: 層により誤差が大きく違う(0.24 対 0.52)。平均ビット数を保ったまま
   感度の高い層へ厚く配分したい。感度の測り方と配分の決め方の定石は。実装が軽い順に。
2. どの層を圧縮しないか: 低ビット化で特に壊れやすい層はどれか。何割を高精度で残すのが定石か。
3. 軽量な再構成: 勾配降下を使わず、閉じた式や少数回反復で層出力を合わせ込む手法で
   効果が大きいものは。
